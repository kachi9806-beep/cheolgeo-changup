# 철거창업소 랜딩페이지

철거업체 창업지원 프로그램 안내 원페이지. 프레임워크 없는 정적 사이트라 빌드 과정이 없음.

## 로컬 확인

```bash
# 방법 1. 정적 서버 (권장)
npx serve .

# 방법 2. 파이썬 내장 서버
python3 -m http.server 5500
```

브라우저에서 `http://localhost:3000` (serve) 또는 `http://localhost:5500` 접속.

## 배포

Vercel 에 GitHub 저장소가 연결되어 있음. `main` 에 푸시하면 운영(365ch.kr)에 자동 배포되고, 다른 브랜치는 미리보기 주소로 배포됨.

## 구성

```
index.html     9개 섹션 마크업 + 상담 모달
privacy.html   개인정보처리방침
styles.css     430px 모바일 컬럼 (좁은 화면은 같은 비율로 축소)
script.js      상담 모달, 사진 슬라이드, 스크롤 등장 효과, 하단 고정 버튼
assets/icons   아이콘 (SVG)
assets/photos  현장·교육 사진 (가로 740px)
```

크기 기준: `html` 글자 크기를 430px 화면에서 10px 로 두고 모든 치수를 `rem` 으로 씀 (1rem = 10px). 430px 보다 좁은 화면에서는 전체가 같은 비율로 줄어듦.

## 사진 슬라이드

`.slider` 안 `.slider__track` 에 `img.slider__slide` 를 넣으면 손가락으로 넘기기와 좌우 화살표, 오른쪽 아래 장수 표시(「1 / 2」)가 자동으로 붙음. 화살표는 끝에서 처음으로 이어짐. 사진은 가로 740px, 슬롯 비율에 맞춰 자른 JPG 로 넣음.

## CTA 동작

- 히어로 「창업 상담하기」, 마지막 섹션 「지금 바로 전화 문의하기」, 하단 고정 버튼 → 상담 모달.
- 마지막 섹션 전화번호 → 바로 전화 연결.
- 하단 고정 버튼은 히어로를 지나면 나타나고 마지막 상담 섹션에 닿으면 사라짐.

상담 모달 안 버튼:

1. 상담 신청하기 → 이름/연락처를 담당자 메일(`kachi9806@gmail.com`)로 접수. 개인정보 수집·이용 동의 체크가 있어야 신청됨. 성공 시 접수 완료 화면 표시.
2. 전화 상담 바로하기 → 대표 전화(`010-2076-5160`)로 연결(`tel:`).
3. 카카오톡으로 편하게 문의하기 → 카카오톡 채널.

### 상담 신청 메일 전달 (Formsubmit)

메일 전달은 서버 없이 [Formsubmit](https://formsubmit.co) 무료 서비스를 사용함 (`script.js`의 `FORM_ENDPOINT`).

- 수신 메일 변경: `script.js`의 `LEAD_EMAIL` 상수 수정.
- 대표 번호 변경: `script.js`의 `OWNER_TEL` 상수와 `index.html`·`privacy.html` 의 `tel:` 링크, 하단 정보 수정.
- 입력값은 브라우저 `localStorage`(`cheolgeo_leads`)에도 백업됨.
